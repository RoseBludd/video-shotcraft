## 0. Why V2 exists

V1 opened on a **Saturday day-clock** ("SAT · 6:00 AM" / "Same storm. Different Saturday.") and treated motion as **one LEAD technique per shot**. Juelzs 2026-10-06 CT rejected that for a tech hero:

1. Door-pin frames zoomed continental US / empty pin panel → hero FAIL.
2. Zero KPIs / empty lists don't teach the product.
3. ~1 affect per shot is too thin — need a **dense Remotion toolkit** (≥100 discrete motion instances).
4. Day-in-the-life clock spine is irrelevant for SaaS launch grammar (Linear / Stripe / Notion / Raycast).

## 2. House grammar (V2 spine)

```
① HOOK (0–3s)          kinetic type / bold claim on near-black — NO product UI yet
② PROBLEM-IMPLIED      one beat of friction implied by the claim (no montage of "chaos")
③ WORKFLOW PROOF       hard-cut evidence ladder: each shot = one buyer question + visible action + outcome
④ OUTCOME              margin / schedule / stack proof
⑤ CTA (last 3–5s)      oversized rooferzs.com · Get started free
```

**Research rules applied (SaaS 2025–2026):**
- ~70% of premium SaaS opens do **not** open on product UI → kinetic claim first.
- No menu navigation; cut straight into proof.
- Real product UI only for claims; motion graphics **annotate** (cursor spotlight, region zoom, callout labels, lower-thirds).
- Hard cuts for speed; subtle **PageCam drift** on static UI; **sharp punch-in** on the interaction.
- Soften / blur inactive UI; isolate the proof (DOF + vignette).
- Sound-off first: **captions carry meaning**.
- Clean demo data that looks like a working company (non-zero KPIs, seeded jobs, $ amounts).
- Homepage length stays **60s / 1800f** (prefer keep; do not expand to 75s unless forced).

## 6. Motion personality (dense, not sparse)

**Old law (V1):** one named LEAD per shot.  
**New law (V2):** every shot stacks **≥3–8 discrete motion instances** (camera + type + annotate + transition + micro). Catalog target: **≥100** across the film (`V2-EFFECTS-CATALOG.md`).

| Layer | Role | Examples |
|---|---|---|
| **A · Camera** | PageCam drift, punch-in, crash zoom, dutch settle, crane rise, whip pan | Isolate proof |
| **B · Optics** | DOF blur inactive UI, vignette, motion blur on whips, focus hand-off | Soften noise |
| **C · Type** | Kinetic stamp, letterspace, scramble, odometer, count-up, chip ripple | Sound-off captions + claims |
| **D · Cursor / annotate** | Bezier cursor, spotlight, L-brackets, callout labels, lower-thirds, region zoom | Prove the click |
| **E · Transition** | Hard cut, flash cut, mask wipe, dark tunnel, card flip, clock wipe **retired** (was day-spine) → use **promise wipe** (glyph morph) | Speed |
| **F · Impact** | Stamp, confetti, white-flash hit, silence window | 3 full-frame hits max |

**Seam preference (V2):** hard cuts + short punch-ins over long tunnels. Keep dark-tunnel **once** (S02→S03) as the only "enter the product" portal. Retire clock-wipe (S15→S16); replace with **mask wipe** or hard cut.
